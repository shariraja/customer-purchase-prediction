# 🛒 Customer Purchase Prediction System

## 🚀 Overview

This project is a Machine Learning-based system that predicts whether a customer will make a purchase or not based on their browsing behavior and session data. It helps businesses understand customer intent and improve conversion rates.

---

## 🧠 Problem Statement

Online businesses often struggle to identify which users are likely to make a purchase. This model solves that problem by analyzing user behavior and predicting purchase probability.

---

## ⚙️ Tech Stack

* Python 🐍
* Pandas, NumPy
* Scikit-Learn
* Random Forest Classifier
* Streamlit (for deployment)
* Pickle (model saving)

---

## 📊 Dataset

* Online Shoppers Intention Dataset
* Features include: page visits, duration, bounce rate, exit rate, etc.

---

## 🤖 Model Workflow

1. Data Preprocessing
2. Exploratory Data Analysis (EDA)
3. Feature Engineering
4. Model Training (Random Forest)
5. Model Evaluation
6. Prediction Interface (Streamlit App)

---

## 📁 Project Structure

* Customer_Purchase_Prediction.ipynb → Model training notebook
* app.py → Streamlit web app
* rf_model.pkl → Trained ML model
* online_shoppers_intention.csv → Dataset
* requirements.txt → Dependencies

---

## 📈 Results

* High accuracy achieved using Random Forest Classifier
* Reliable prediction of customer purchase behavior

---

## 🚀 How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
```
